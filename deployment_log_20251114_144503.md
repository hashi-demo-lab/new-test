   - Enforce security policies (encryption at rest/transit, MFA, least privilege IAM)
   - Require mandatory tags (CostCenter, Owner, Environment)

2. **HTTPS Configuration:**
   - Replace self-signed SSL certificates with ACM certificates
   - Add HTTPS:443 listener to ALB
   - Redirect HTTP to HTTPS for production traffic

3. **Backup & DR:**
   - Configure EC2 instance backups (AWS Backup or snapshots)
   - Document RTO/RPO requirements
   - Implement cross-region replication for critical data

4. **Monitoring & Alerting:**
   - Configure CloudWatch alarms for ALB 5xx errors, unhealthy targets
   - Set up SNS notifications for infrastructure failures
   - Implement application-level monitoring (APM)

5. **Auto-Scaling:**
   - Replace static EC2 instances with Auto Scaling Group
   - Configure scaling policies based on CPU/memory/request count
   - Ensure minimum 2 instances for high availability

6. **Security Hardening:**
   - Implement WAF rules for ALB (OWASP Top 10 protection)
   - Enable VPC Flow Logs for network traffic analysis
