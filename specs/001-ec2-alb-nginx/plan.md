# Implementation Plan: EC2 Web Infrastructure with Application Load Balancer

**Branch**: `001-ec2-alb-nginx` | **Date**: 2025-11-14 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/workspace/specs/001-ec2-alb-nginx/spec.md`

## Summary

Deploy high-availability web infrastructure using 2x t3.small EC2 instances across 2 availability zones in ap-southeast-2, fronted by an internet-facing Application Load Balancer. Instances run Nginx with self-signed SSL certificates, supporting independent HTTP/HTTPS listeners. Infrastructure uses existing default VPC and leverages private Terraform modules from hashi-demos-apj registry. Optimized for development environment with minimal cost (<$50/month).

**Technical Approach**: Module-first architecture using `hashi-demos-apj/ec2-instance/aws` (v6.1.4), `hashi-demos-apj/alb/aws` (v10.1.0), and `hashi-demos-apj/security-group/aws` (v5.3.1) from private registry. User data script installs Nginx with self-signed certificates. ALB health checks target HTTP:80/health endpoint.

### Technology Decisions

| Decision | Choice | Rationale | Alternatives Considered |
|----------|--------|-----------|------------------------|
| **SSL/TLS Strategy** | Self-signed certificates | User clarification: acceptable for dev, no domain name cost | AWS Certificate Manager (requires domain), Let's Encrypt (requires DNS validation) |
| **HTTP Behavior** | Independent HTTP/HTTPS listeners | User clarification: testing flexibility | HTTP→HTTPS redirect (rejected), HTTPS-only (rejected) |
| **Instance Type** | t3.small (2 vCPU, 2 GB RAM) | User clarification, performance headroom for Nginx | t3.micro (insufficient memory), t3.nano (too constrained) |
| **Health Check Config** | 10s interval, 5s timeout, 2 failures | Meets NFR-003 (20s detection) while avoiding false positives | 5s/3s/3 (too aggressive), 15s/5s/2 (marginally meets requirement) |
| **ALB Scheme** | Internet-facing | User clarification: public accessibility required | Internal ALB (rejected - limits testing) |
| **Nginx Installation** | User data bash script | Development simplicity, fast iteration, comprehensive logging | AMI baking (slow iteration), Ansible (over-complex), cloud-init YAML (less debuggable) |
| **Certificate Validity** | 365 days | Balance convenience and security for dev | 90 days (too frequent renewal), 730 days (too long for practice) |
| **Health Check Endpoint** | HTTP:80 /health | Avoids SSL overhead, simpler debugging, no cert validation issues | HTTPS:443 (more complex), port 8080 (separate listener) |
| **Subnet Strategy** | Public subnets (existing default VPC) | Cost optimization (no NAT Gateway), specification constraint | Private + NAT Gateway (adds $32-45/month cost) |

### AWS Best Practices Integration

**Security Architecture** (from aws-security-advisor subagent):

1. **Security Groups**:
   - ALB: Allow 0.0.0.0/0:80,443 → ALB
   - EC2: Allow ALB_SG:80,443 → EC2 (security group referencing)
   - EC2: Allow 0.0.0.0/0:443 → Internet (egress for packages)
   - EC2: No port 22 (SSH) - use Systems Manager Session Manager

2. **IAM Instance Profile**:
   - `AmazonSSMManagedInstanceCore` (managed policy)
   - CloudWatch Logs write permissions (custom policy, scoped to `/aws/ec2/nginx/*`)
   - CloudWatch Metrics put permissions (custom policy, scoped to namespace)

3. **TLS Configuration**:
   - ALB listener policy: `ELBSecurityPolicy-TLS13-1-2-2021-06` (TLS 1.2/1.3 only)
   - Nginx SSL: TLS 1.2+ with strong ciphers

4. **Monitoring**:
   - VPC Flow Logs (optional for dev, ~$5-15/month)
   - ALB access logs to encrypted S3 bucket (~$2-5/month)
   - CloudWatch alarms: UnhealthyTargets, 5XX errors, response time

## Phase 1: Design & Architecture

### High-Level Architecture

```
Internet
    ↓
Internet Gateway (default VPC)
    ↓
Application Load Balancer (internet-facing)
│   Subnets: ap-southeast-2a, ap-southeast-2b (public)
│   Listeners: HTTP:80 (forward), HTTPS:443 (forward)
│   Security Group: Allow 0.0.0.0/0:80,443
    ↓
Target Group (nginx-instances)
│   Protocol: HTTP:80
│   Health Check: HTTP:80/health (10s interval, 5s timeout, 2 failures)
    ↓
EC2 Instances (2x t3.small)
│   AZ: ap-southeast-2a, ap-southeast-2b
│   AMI: Amazon Linux 2023 (via SSM parameter)
│   User Data: Install Nginx + self-signed SSL
│   Security Group: Allow ALB_SG:80,443 only
│   IAM Profile: Session Manager + CloudWatch
    ↓
Nginx (HTTP:80, HTTPS:443)
│   HTTP: /health endpoint + redirect to HTTPS
│   HTTPS: Self-signed cert, TLS 1.2+
```

### Module Composition

**Main Configuration** (`main.tf`):

```hcl
# Data source: Get default VPC
data "aws_vpc" "default" {
  default = true
}

# Data source: Get default VPC subnets in 2 AZs
data "aws_subnets" "default" {
  filter {
    name   = "vpc-id"
    values = [data.aws_vpc.default.id]
  }
  filter {
    name   = "availability-zone"
    values = ["ap-southeast-2a", "ap-southeast-2b"]
  }
}

# Module: ALB Security Group
module "alb_security_group" {
  source  = "app.terraform.io/hashi-demos-apj/security-group/aws"
  version = "~> 5.3.1"

  vpc_id      = data.aws_vpc.default.id
  name        = "alb-sg"
  description = "Security group for internet-facing ALB"

  ingress_with_cidr_blocks = [
    {
      from_port   = 80
      to_port     = 80
      protocol    = "tcp"
      cidr_blocks = "0.0.0.0/0"
      description = "HTTP from internet"
    },
    {
      from_port   = 443
      to_port     = 443
      protocol    = "tcp"
      cidr_blocks = "0.0.0.0/0"
      description = "HTTPS from internet"
    }
  ]

  egress_with_cidr_blocks = [
    {
      from_port   = 0
      to_port     = 0
      protocol    = "-1"
      cidr_blocks = "0.0.0.0/0"
      description = "All outbound traffic"
    }
  ]
}

# Module: EC2 Security Group
module "ec2_security_group" {
  source  = "app.terraform.io/hashi-demos-apj/security-group/aws"
  version = "~> 5.3.1"

  vpc_id      = data.aws_vpc.default.id
  name        = "ec2-nginx-sg"
  description = "Security group for EC2 Nginx instances - allows traffic from ALB only"

  ingress_with_source_security_group_id = [
    {
      from_port                = 80
      to_port                  = 80
      protocol                 = "tcp"
      source_security_group_id = module.alb_security_group.security_group_id
      description              = "HTTP from ALB"
    },
    {
      from_port                = 443
      to_port                  = 443
      protocol                 = "tcp"
      source_security_group_id = module.alb_security_group.security_group_id
      description              = "HTTPS from ALB"
    }
  ]

  egress_with_cidr_blocks = [
    {
      from_port   = 443
      to_port     = 443
      protocol    = "tcp"
      cidr_blocks = "0.0.0.0/0"
      description = "HTTPS for package updates and AWS APIs"
    },
    {
      from_port   = 80
      to_port     = 80
      protocol    = "tcp"
      cidr_blocks = "0.0.0.0/0"
      description = "HTTP for package repositories"
    }
  ]
}

# Module: Application Load Balancer
module "alb" {
  source  = "app.terraform.io/hashi-demos-apj/alb/aws"
  version = "~> 10.1.0"

  name    = "nginx-alb"
  vpc_id  = data.aws_vpc.default.id
  subnets = data.aws_subnets.default.ids

  internal                  = false  # Internet-facing
  enable_deletion_protection = false # Development environment

  security_groups = [module.alb_security_group.security_group_id]

  # HTTP Listener (port 80)
  listeners = {
    http = {
      port     = 80
      protocol = "HTTP"
      forward = {
        target_group_key = "nginx_instances"
      }
    }
  }

  # Target Group
  target_groups = {
    nginx_instances = {
      name_prefix = "nginx-"
      protocol    = "HTTP"
      port        = 80
      target_type = "instance"

      health_check = {
        enabled             = true
        interval            = 10  # FR-006, NFR-003
        timeout             = 5   # FR-006
        healthy_threshold   = 2
        unhealthy_threshold = 2   # FR-006
        path                = "/health"
        port                = "traffic-port"
        protocol            = "HTTP"
        matcher             = "200"
      }
    }
  }
}

# Module: EC2 Instances (2 instances across 2 AZs)
module "ec2_instance_az1" {
  source  = "app.terraform.io/hashi-demos-apj/ec2-instance/aws"
  version = "~> 6.1.4"

  name          = "nginx-instance-az1"
  instance_type = "t3.small"  # FR-008

  subnet_id              = data.aws_subnets.default.ids[0]
  vpc_security_group_ids = [module.ec2_security_group.security_group_id]

  ami_ssm_parameter     = "/aws/service/ami-amazon-linux-latest/al2023-ami-kernel-default-x86_64"
  create_iam_instance_profile = true
  iam_role_policies = {
    SSM    = "arn:aws:iam::aws:policy/AmazonSSMManagedInstanceCore"
    CloudWatch = # Custom policy for logs
  }

  user_data = templatefile("${path.module}/user_data.sh", {})

  # Attach to ALB target group
  target_group_arns = [module.alb.target_groups["nginx_instances"].arn]
}

  source  = "app.terraform.io/hashi-demos-apj/ec2-instance/aws"
  version = "~> 6.1.4"

  # Same configuration as az1, different subnet
  name          = "nginx-instance-az2"
  instance_type = "t3.small"
  subnet_id     = data.aws_subnets.default.ids[1]
  # ... (identical configuration)
}
```
